# Week Three - Battles P1
This is part one of 3 devlogs, this weeks main goal is to establish a battles system that can be extended, 
and creates a challenging difficult system. To start last week i completed the general look of the scene
going for a pokemon inspired look. In addition i polished it and added stamina mechanics, a time based 
system, and menus

## Timed Attacks
So during my initial testing of the different menus and attacks i found i could simply just, press the same
attack and easily wipe the enemy in like 2 seconds, this defeats the purpose of an attack, so instead i made each attack tied to the enemys turntimer, one attack per enemy timer, one defensive posture, and a unlimited amount of item usage and spells. So far the system has seemed to work.

## Stamina
Currently i working on defensive moves which will cost stamina, ive also added a stamina cost to attacks, which stamina will regenerate every second, or you can cast spells to add stamina, aswell as potions
