## Database Structure

# Player accounts
- Player Id -- will be stored in uuid form this will be general primary key for anything player related the user id is the key to all actions
- player username -- username created on account creation
- player passphrase -- stored passphrase in hash pulled from users computer to act as an auth
- player passphrase filename -- stored filename for hash file
- last login -- last time user logged into service
- account creation -- date when account was created
- account status -- active, terminated, banned, deleted (backround jobs to clean accounts)

# ssh keys
- ssh key id -- uuid identifier for ssh key generated by server
- player id -- stored in uuid form connects to player accounts
- public key -- public key from user mainly for auth and recognition
- key fingerprint -- unique identifier from public key main auth
- key label -- ssh connection descriptor (ie gaming desktop / linux)
- created at -- first login timestamp
- last_used -- last login timestamp

# Player progression
- player Id -- uuid connected to player accounts
- player lvl -- the players level 
- curr exp -- experience player has used to calc how much exp to go
- health -- players current health
- maxhealth -- players max health
- attribute dict -- relative attributes for hero in a dict
- talent tree - user talent tree in dict form
- talent points - any unused talent points
- currency -- amount of $ someone has

# World state
- Player Id -- uuid connected to player accounts
- gameStage -- main gamestage sections ##-#### (first 2 are main stage area, last 4 is sectional)
- Location Id -- after tutorial location area id
- cordinates -- when location id is present a cordinate is also there
- Discovered Locations -- location id that have been discovered
- activated mechanisms -- all mechanism ids that have been activated
- defeated unique enemys -- all enemy ids that have been defeated
- shortcuts and fast travel -- ids for fast travel and shortcuts

# Player inventory
- Player id -- uuid connected to player accounts
- weapons -- All weapons in the player inventory + magical wands
- armor -- all armor in players_inventory
- spells -- all spells the player has access to + quantity of each
- consumables -- player consumables 
- Speciality_items -- any item that is a speciality item
- player loadout -- json format the players currently equiped loadout (weapon, armor, active passives)
